## 👨‍💻 About Me

I'm an **AI Engineer and Full-Stack Software Engineer** focused on building intelligent, reliable, and production-ready software.

My work spans **AI agents, Retrieval-Augmented Generation (RAG), tool calling, semantic search, real-time systems, backend architecture, and modern web applications**.

I enjoy working on systems where AI has to do more than generate text — systems where models need to retrieve accurate information, call tools safely, interact with application state, and produce useful results inside real products.

- 🤖 Building **RAG systems, AI agents, tool-calling workflows, and semantic search**
- 🧠 Working with **LangGraph, LangChain, Gemini API, and LLM-based systems**
- ⚡ Developing APIs and backend systems with **FastAPI, Node.js, Express, and Spring Boot**
- 🎨 Building responsive applications with **React, Next.js, Tailwind CSS, GSAP, and Three.js**
- 🗄️ Working with **Supabase, Firebase, Firestore, MongoDB, and SQL**
- 🔐 Interested in **AI guardrails, reliable tool execution, authorization, and production AI architecture**
- 🎓 Bachelor of Engineering in **Computer Engineering — Alexandria University**
- 📍 Alexandria, Egypt
- 💬 Open to conversations about **AI Engineering, Full-Stack Development, RAG, and Agentic Systems**
